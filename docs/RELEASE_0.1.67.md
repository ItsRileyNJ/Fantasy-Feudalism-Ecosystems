# November 23, 2026 — Version 0.1.67 — Changelog

- **Scorpion texture:** Normal Scorpions now have earthy brown mottling and scattered stone-colored flecks inspired by coarse dirt.

The material atlas retains its quadrant UV layout, with darker mouthparts, pincers and stinger and bright eyes. Crystapid textures, geometry and gameplay remain unchanged. Source provenance is recorded in the model-sources documentation.

Release and multiplayer-harness builds passed. A native client connected to the dedicated server with Mercenaries, Farmer's Delight, Passable Foliage and Kiwi installed; both variants rendered with finite transforms and no render errors. The normal Scorpion texture packaged in the JAR matches the updated asset, and the Crystapid texture is byte-identical to the preceding commit. Gameplay tests were not rerun for this texture-only change.
